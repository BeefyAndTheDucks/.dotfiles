# My .dotfiles

## Dependencies

### Shell (zshrc)
zsh (dnf)

fzf (dnf)

zoxide (dnf)

starship (https://starship.rs/ use the COPR)

fzf-tab (https://github.com/Aloxaf/fzf-tab#install - clone into ~/.config/zsh/plugins/fzf-tab/)

zsh-autosuggestions (dnf)

zsh-autopair (https://github.com/hlissner/zsh-autopair#install - clone into ~/.config/zsh/plugins/zsh-autopair/)

zsh-syntax-highlighting (dnf)

**OPTIONAL:**
neovim (dnf) - default editor

eza (dnf) - directory previews

trash-cli (dnf) - `del` alias

wl-clipboard (dnf) - `h` history alias

qdbus (dnf) - preinstalled with KDE, `wprop` alias (xprop equivelant for Wayland)

dnf and flatpak (dnf) - for `update` and `install` alias (`install` is only for DNF.)

fish (dnf) and zsh-manpage-completion-generator (https://github.com/umlx5h/zsh-manpage-completion-generator) - for autocompletion generation with the `zsh_update_completions` function

playit (https://github.com/playit-cloud/playit-agent) - for `start-playit`, `stat-playit` and `stop-playit` alias

SELinux - for `fix-perms` alias

### Terminal
kitty (dnf)

JetBrains Mono NerdFont NL (https://www.nerdfonts.com/font-downloads)

### Editor
neovim (dnf)
